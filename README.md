# Marketing-Campaign-Performance-
## Project Overview
The Marketing Capstone Project is an end-to-end data analytics project that analyzes marketing data using Microsoft Excel, SQL, and Power BI.

The project focuses on transforming raw marketing data into meaningful insights and interactive dashboards. It helps analyze marketing performance, customer behavior, conversion rates, social media engagement
## Tools & Technology
- Microsoft Excel
- Power BI
- sqL
### Microsoft Excel
- Data collection and initial data exploration
- Data cleaning and preprocessing
- Performed Pivot Tables and analyze the marketing business performance reports  
### Power BI
- Data transformation using Power Query
- Data modeling
- Devoloped DAX measure and KPI
-  Data Modeling process and created relationship between multiple Table
-  Devoloped Interactive Dashboards and Visualized marketing overall Business performance
